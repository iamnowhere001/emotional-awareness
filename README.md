# 心情闯关岛

> 一起认出心里的天气。按年龄分级的情绪启蒙小游戏：**纯前端 · 零依赖 · 不联网 · 不打分 · 不采集心情文本**。
>
> 当前版本 **0.17.0**（0.x 预发布台阶，历史批次已自 v0.1.0 重排，见 [CHANGELOG.md](CHANGELOG.md)）｜后续安排见 [ROADMAP.md](ROADMAP.md)

这不是心理测评，也不能代替专业帮助。它做的事只有一件：把模糊的感觉看得更清楚一点，再带走一个用得上的小工具。

---

## 1. 快速开始

| 方式 | 操作 | 适用场景 |
| --- | --- | --- |
| 直接打开 | 双击 `index.html` | 日常使用。`file://` 下完整可玩，已实测 |
| 本地服务 | `npm run serve` → `http://localhost:5173` | 手机同网段预览；以后加 service worker 需要 http |

`npm run serve -- 8080`（或 `node scripts/serve.mjs 8080`）可指定端口。**应用本身不需要 Node、不需要构建、不需要安装依赖**；Node.js 18+ 只用于内容自检、本地静态服务和浏览器回归。

首次进入先选年龄段，之后从设置里可随时更换；换档保留进度、词卡和本领，不会覆盖用户手动调过的字号与朗读偏好。

## 2. 内容规模（当前实测）

| 项目 | 数量 |
| --- | --- |
| 年龄档 | **4 档**：`a3` 3-6 岁 / `a6` 6-12 岁（合并档，带基础 / 多想一步两层）/ `all` 亲子全年龄 / `adult` 成年。旧档 `a9` 由 `BAND_REMAP` 落到 `a6`，存档不丢 |
| 关卡轨 | 2 条：儿童与亲子共用 `kid`；成年独立 `adult` |
| 岛屿 | 每轨 4 座（儿童：察觉湾 / 调节林 / 联结港 / 安放角；成年：觉察滩 / 调节林 / 联结港 / 安放角） |
| 站点 | 每轨 **17 站 = 16 关 + 终章** |
| 玩法 | 13 种互动题型 + 终章，共 14 个 `type`；静修间另有 `sit` 引导 |
| 题库变体 | 儿童 **91 组**，成年 **32 组**，合计 123 组；每档每关至少 2 组。儿童池按 `tier: 1 / 2` 分两层，6-12 岁合并档每关可抽 **3～5 组**（原每关 2 组） |
| 内容库 | 概念层 16 条（站点 / 工具卡 / 词典 / 慢变量共用同一概念 id）· 词卡释义 27 条（按 16 个概念成组，其中 11 组是两轨双名）· 聊卡 10 · 微行动 8 · 装饰 6 · 漂流瓶 16 · 静修练习 10 · **冥想练习 10（5 族 × 2 档 / 6 场景 / 8 句 if-then）** · **心理学词典 162 条（4 大组 / 11 主题 / 45 个概念簇 / 4 类概念，每条带关联词条）** · **自助工具 31 张 + 认知扭曲 10 条速查** · **慢变量 6 个 + 练习 12 张（按 6 变量归属，数量不等）+ 尺度 3 个 + 陷阱 10 个** · **急救入口 3 个 1 分钟动作 + 4 条本地求助信息** |

两条轨的关卡 `id` 前缀不同（儿童 `1-1…4-4 / finale`，成年 `A1-1…A4-4 / A-finale`），进度天然隔离，`clearedInTrack()` 各算各的；成年档不显示也不发放贝壳。**词卡也按轨记录**（`state.cards = { kid, adult }`）：两轨同名的 5 张卡（觉察 / 身体信号 / 强度 / 火气分级 / 边界）在各自图鉴里独立解锁，不会因为玩过儿童档就点亮成年图鉴；另有 11 组概念两轨叫法不同（如 情绪粒度 / 命名）。图鉴在渲染层按 16 个概念合并成组并标出另一种叫法，**存档键值仍是原来的 5 + 11 张卡名，schema 不变**。

### 3.1 两种打开方式

- **双击 `index.html`（`file://`）**：内容、玩法、导出、导入、`#/level/x` 直达全部可用；service worker 只在 `http(s)` 下注册，`file://` 下直接跳过，不报错也不白屏。
- **本地静态服务（`npm run serve`，`http://localhost:5173`）**：额外获得「安装到主屏 / 离线打开」。`sw.js` 预缓存全部静态资源，缓存名带 `VERSION`；新版本发布时 `VERSION` 变化会让旧缓存在 `activate` 阶段被清掉，页面导航走网络优先、失败才用缓存，避免旧版卡住不更新。应用本身仍然零远程请求：报文只来自同源的本地文件。

**为什么不用 ES module**：`content/*.js` 与 `js/*.js` 都用经典 `<script>` 顺序加载，是为了让双击 `index.html` 的 `file://` 场景也能跑（ES module 在 `file://` 下会被 CORS 拦住）。`index.html` 里的顺序是契约：

`bands → levels-kid → levels-kid-island4 → levels-adult → bank-kid-1-3 → bank-kid-island4 → bank-adult-1-3 → bank-adult-island4 → bank-compose → levels-adult-work → library → meditate → dictionary → selfhelp → slowvars → help → js/core → js/util → js/shell → js/views-main → js/views-library → js/views-level → js/ui → js/actions → js/boot`

顺序错了或文件缺失，`js/boot.js` 启动时会显示「内容没加载出来」的可读提示，不会白屏。九块逻辑脚本共用同一个全局词法作用域（`let/const` 跨脚本可见，不挂 `window`），因此**同一顶层名字只能声明一次**；`npm run check` 会把九块拼起来再解析一次，专门拦跨文件重复声明。

## 4. 怎么加内容

### 4.1 加一组变体（最常见）

在对应的 `bank-*.js` 里往**已有的**该关数组末尾追加一条，带上档位标记 `b`；儿童 / 亲子轨还要带 `tier`（`1` 基础 / `2` 多想一步）：

```js
/* 注意是 push，不要用 Object.assign 覆盖整个键——那会把已有变体清掉 */
(MI.bankKid['4-2'] ||= []).push({
  b: ['a6', 'all'], tier: 1,
  scenario: '……', question: '现在大概到哪一档？',
  rungs: [{ label: '一档', body: '……', move: '……' }]
});
```

`b` 省略表示该组对所有档可用；`pickVariant()` 按当前档过滤，6-12 岁合并档再按当前深度层过滤（没走过的站默认 `1`，走过一次或手动切换后为 `2`；某层为空时回落到该档全部题）。深度层只存在 `session.depth` 里，不落盘。新关卡第一次建键时才用 `Object.assign(MI.bankKid, { 'x-y': [...] })`。

### 4.2 加一站

1. 在 `levels-*.js`（或新建的 `levels-*-islandN.js`）里加一条关卡对象，**必须插在终章之前**；照 `levels-kid-island4.js` 的 IIFE + `splice` 写法最省事；
2. 在对应题库文件里加同名键，每档至少 2 组变体；儿童轨还要保证 `tier: 1` 至少 2 组、`tier: 2` 至少 1 组（lint 会校验）；
3. 如果这一站带新词卡，在 `library.js` 的 `CODEX` 里补释义和例子；再到 `content/glossary.js` 把该站 id 挂到对应概念的 `stations`（通关结果卡据此取「为什么可能有用」和动作规格，漏挂 lint 会提示）。

关卡对象字段：`id / island / num / name / type / kind / card / skill / goal / tip / hint / tryIt / adult`。终章固定 `island: 0` 且 `type: 'finale'`，**必须排在数组最后**；位置错了 lint 会直接报错。

### 4.3 加一座岛

照 `levels-kid-island4.js` + `bank-kid-island4.js` 的写法：关卡文件用 IIFE 把新站 `splice` 到终章之前，题库文件用 `Object.assign` 合并；然后在 `MI.kid.islands`（或 `MI.adult.islands`）加一条岛屿描述，最后在 `index.html` 里按依赖顺序插入两行 `<script>`。**别忘了把新文件名加进 `scripts/lint-content.mjs` 顶部的 `FILES` 数组**，否则自检不会读到它。

### 4.4 加一种题型

需要动四处：`js/views-level.js` 的 `RENDERERS`（渲染）与 `makePlay`（初始化 play 状态）、`js/actions.js` 的 `ACTIONS`（交互处理）、`style.css`；以及 `lint-content.mjs` 的 `TYPES` / `NEED`。参考 `ladder` 这个题型，它是最小实现。

### 4.5 加 / 改词典词条

词典是独立数据文件 `content/dictionary.js`：`MI.dictionary` 是词条数组，`MI.dictionaryMeta` 定义分组与概念类型。每条字段：

```js
{
  t: '依恋', e: 'Attachment', c: '发展与人格', k: 'core',
  s: '一句话释义（卡片正面）',
  d: '展开解释，写清边界与争议',
  m: '常见误解（可选，暖色块单独显示）',
  r: ['气质', '亲密关系中的依恋']       // 可选：关联词条，渲染成「接着看」
}
```

- **数量不设上限**。0.8.2 起取消「固定 100 条」，`npm run lint` 只保留一条「少于 100 条即报错」的防误删下限。加词条不必删旧词条，也不必同步改测试里的数字（浏览器用例一律读 `DICTIONARY.length`）。
- `c`（主题）与 `k`（概念类型）**只认 `MI.dictionaryMeta`**：`groups[]` 的 `cats` 展开即合法主题，顺序就是词典页的分区顺序；`kinds[]` 的 `id` 是合法类型。当前 **4 个大组 / 11 个主题 / 4 种类型**（`core` 入门核心 / `frontier` 当代议题 / `method` 方法与证据 / `myth` 容易误读）。`myth` 的判据是「概念名所指的现象或工具本身被证据削弱、或效果被明显夸大」（自我损耗、MBTI、学习风格）；概念成立、只是流传版本有误的（工作记忆、神经可塑性、确认偏差一类）用 `core / frontier`，边界写进 `m` —— 0.17.0 校准前有 20 条被错标，判定标准另见 `content/dictionary.js` 头注释。**新增主题或类型只改数据文件**，不用动 `lint-content.mjs` 与 `js/core.js`。
- **顺序即阅读路径**：`groups[]` 顺序是大组顺序，`MI.dictionary` 数组顺序就是卡片顺序，同主题词条必须连续。主线是「先看见自己的状态 → 再理解心智怎么运作 → 从自己走向他人 → 数字时代与证据素养」；每个主题内部按「是什么 → 机制 → 能用的策略 → 成组对照 → 流行说法的边界」排。`catMeta[主题]` 的 `lead` 是主题导语，`clusters[].start` 只声明该簇第一条，簇边界由数组顺序派生，不在数据里重复存一份名单；`lint` 会校验起点真实存在、单调递增、首簇起点等于主题首条。主题名与 162 条正文不变，只调顺序与归属时不改任何文案。
- **五步起步路径**在 `js/views-library.js` 的 `DICT_START_PATH`，只引用已有词条、复用 `dict-jump`，不新增筛选维度；改起点时确认词名真实存在即可。
- 必填 `t / e / c / k / s / d`，`t` 不重复；`r` 若给出，必须是真实存在的词条名、不能指向自己、不能重复。改完跑 `npm run lint`，它会校验字段、主题、类型、关联引用、名词去重、每个主题 / 类型都有词条与文案长度，以及主题导语与概念簇起点。

## 5. 存档与迁移

| 项 | 值 |
| --- | --- |
| 当前键 | `mood-island-v5` |
| 旧键 | `mood-island-v4`（0.10.0 及更早）、`mood-island-v3`（0.7.0 及更早）、`mood-island-v2`（读到后自动迁移；正常升级时**旧键保留**以便回退，「清空本机进度」会连旧键一起删除） |
| schema 版本 | `SCHEMA_VERSION = 5` |
| 字段 | `version, band, cleared, awarded, cards{kid[],adult[]}, skills, shells, decor, seen{关id:[组合键]}, sideCleared[], settings{scale, motion, speak, speakTouched, autoSpeak, contrast}` |
| id 改名 | `ID_REMAP = { '3-5': 'finale' }`，旧终章进度不会丢 |
| 档位改名 | `BAND_REMAP = { 'a9': 'a6' }`，6-9 与 9-12 合并后旧档 / 旧导出 JSON 里的 `a9` 落到 `a6`；其余字段一字不动，`SCALE_VALUES` 显式保留老档可能设过的 `1.06` |

`load()` → `readRaw()`（v5 优先，v5 损坏或不存在时依次回退 v4 / v3 / v2）→ `migrate()`。**以后加任何字段，都在 `migrate()` 里补一段白名单式默认值**，不要直接改 `DEFAULT_STATE` 就完事，否则老用户进度可能被静默重置。`migrate()` 还会逐项清掉无效数据：未知关卡 id、重复的 `cleared / awarded`、内容里已不存在的词卡与本领、越界或重复的 `decor` 下标、负数或小数的 `shells`、不在允许档位里的 `settings.scale`、不存在的拼装组合键、越界的支线 id；其余字段不受影响，所以旧档和现有 v5 档都不会被整体重置。

**v4 → v5 只加两个字段**：`seen`（拼装题已出现过的组合键，按关分桶，每关最多 8 条，超出丢最旧）与 `sideCleared`（成年「工作间」支线完成记录，白名单只认 `W-1…W-4`）。主线 `cleared / awarded / cards / skills / shells / decor` 的迁移路径一字未改；`sideCleared` 不计入 17 站、不加贝壳 / 词卡 / 本领，也不参与终章解锁。`seen` 不是可见进度，界面上不显示任何组合计数；`restart-all` 不清它，「清空本机进度」才删。

**v3 → v4 只改词卡语义**：旧档的 `cards` 是不分轨的数组，`migrateCards()` 按以下顺序推断归属——① 只在一轨出现的卡，直接归该轨；② 两轨同名的卡，对应关卡有通关 / 领贝壳记录就归该轨，两轨都有记录则两边都算真拿到；③ 对不上记录时，只玩过一轨就归那一轨；④ 两轨都玩过但仍无法判定，归**儿童档**（宁可少给成年档，也不把儿童卡虚增成成年卡）。`cleared / awarded` 不受影响。

**`skills` 暂不按轨拆分**：两轨现在没有同名本领，所以共用一份数组不会串档；回归会断言两轨本领名不重复。以后若要复用同一个本领名，必须先把 `skills` 拆成按轨结构并补迁移，否则会在另一轨提前点亮。词卡已经按轨拆分（`cards: { kid, adult }`），不受这个约束影响。

**回退**：正常升级时旧键从不被新代码覆盖，旧版本代码仍读 v4；升级后产生的新进度只写 v5，回退到旧代码会看不到升级后的新进度，但不会破坏旧档，也不会把词卡串档。用户点「清空本机进度」是明确的删除动作，会移除 v5 / v4 / v3 / v2，之后不能再靠旧键找回。

**不会保存**：开场选的天气、任何心情文本（应用不提供心情输入框；词典搜索框只做本地过滤）、心理学词典的主题 / 类型 / 搜索词（每次重新打开都会清空）、自助工具箱选中的状态与分类、慢变量选中的变量与分类（每次重新打开都会清空）、冥想练习的当前场景 / 剂量 / 带回句（只在本次打开期间）、练习次数、静修间做过几次。隐私 / 无痕模式下若 `localStorage` 不可写，页面会常驻一条说明、设置页同步提示，不会谎报「已保存」。

**已决取舍**：v0.6.0 之前成年档与儿童档共用 `1-1…3-4` 这些 id；双轨拆分后这些 id 归儿童轨，成年轨会显示为「未走过」。两套题本来就不同，**目前处于开放阶段，明确不做进度映射，也不再排期**。

### 5.1 导出 / 导入

设置页「备份与迁移」可以导出一个 JSON。载荷固定为：

```js
{
  app: 'mood-island',
  exportVersion: 1,          // 导出格式号，只在载荷形状变化时 +1，与 package 版本、SCHEMA_VERSION 无关
  exportedAt: '2026-11-07T…Z',
  state: { /* 上表的全部存档字段 */ }
}
```

文件名是 `mood-island-progress-YYYYMMDD-HHmm.json`（本机本地时间，分钟粒度）。导入按外部输入处理：依次检查 JSON 语法、`app` 标识、`exportVersion`（比当前新就拒绝并提示先更新游戏）、`state` 是否存在、`state.version` 是否超前、是否含有可识别进度；任何一项不过都给出具体原因，当前档不动。通过后先弹「导入前先看一眼」，把文件与当前设备的年龄段、两轨站数、词卡、本领、贝壳并排显示，用户确认才覆盖；覆盖前会走 `migrate()`，所以旧结构（如 v3 的不分轨词卡）也能导入。覆盖前的那一份只留在内存里，本次打开期间可撤销一次，不新增任何持久键。

### 5.2 直达链接

地址形如 `#/map`、`#/level/4-2`、`#/work`、`#/level/W-1`、`#/help`、`#/dict`、`#/selfhelp`、`#/slowvars`、`#/retreat`、`#/home`、`#/gate`，刷新、收藏、分享都不会丢站。`http(s)` 下每次换屏用 `history.pushState` 入栈，`boot.js` 的 `popstate` 把浏览器后退 / Android 物理返回键 / iOS 侧滑映射回上一屏（弹窗打开时先收掉遮罩）；首次写入与坏地址纠正仍用 `replaceState`，不凭空多一条历史。`file://` 下 `pushState` 常被拒，保持原来的 `replaceState` + `location.hash` 回落，双击打开的行为一字不变。页内目录锚点（`#dict-group-x`、`#sv-practices` 等）在点击委托里被拦下，只滚动本页分区，不进 hash 路由。只认当前轨的关卡 id：未知地址、另一条轨的站、尚未解锁的站都回落地图（无档时回选档页），并把地址改回合法值，不留在坏链接上。`#/work` 与 `#/level/W-x` 只在成年轨可用；儿童 / 亲子轨视作不可达，未解锁的幕次回落到工作间时间线。

## 7. 设计红线（改动前先读）

1. **不打分、不排名、不比速度**：没有分数、正确率、倒计时、失败惩罚、红叉、连签、排行榜。答错给中性提示，连续两次未命中自动给 `hint`。
2. **不采集心情文本**：没有心情自由输入框，天气选择不落盘，不记练习次数。漂流瓶选哪一项都给同一句回应，没有对错。心理学词典的搜索框只在当前页面内过滤词条，不保存、不上传，也不接收心情文本；主题与类型筛选同样只在内存里，每次重新打开都会清空。自助工具箱与慢变量只提供阅读与选择，不收集自由文本，选中的状态、变量和分类只留在内存里，慢变量每次重新打开都会清空。
3. **不联网**：没有 fetch/XHR、没有第三方脚本、字体、图标或 CDN；朗读调用设备自带语音能力。PWA 的 service worker 只缓存同源静态文件，不发起任何远程请求，也不上报任何数据。
4. **不宣称疗效**：不是心理测评、不是诊断、不能代替专业帮助；页脚与静修间双重免责，呼吸/正念练习可睁眼、随时停止。「睡不着」组不承诺助眠，只说「不把睡着当任务」。
5. **不制造回来的压力**：不打卡、不连续登录奖励、进度不会掉；静修间按场景与练习族排列，不是打卡系统，也不记录次数 / 连续天数 / 时长；练习可随时停，停了不算失败。
6. **正确答案不能恒在第一项**：`clue / reframe / defuse / compose` 渲染前洗牌，判对错读 `data-orig` 的原始下标。

新增内容若碰到这些边界，先改设计再写代码。`lint-content.mjs` 会扫红线词，但最终仍需要人工判断语境。

## 8. 键盘与无障碍

- 选项左侧徽标是 **1 / 2 / 3…**，直接对应数字键。`1`–`9` 覆盖所有使用 `.opt` 的选择题（线索单选、换视角 `reframe`、终章金句、静修「第一反应」）以及漂流瓶弹窗里的选项；梯子的档位号也能按。天气、配对、滑杆、排序、拼句、记忆牌没有数字键，仍用 Tab / 点击。
- `Esc` 关弹窗 / 回地图，`←` `→` 在已解锁的站之间切换（仅关卡视图）。地址栏的 `#/…` 只是当前屏的同步结果，不参与 Esc / 返回的判断。
- 心理学词典的卡片用原生 `details / summary`：Tab 可聚焦，Enter / 空格展开；搜索框可输入，分类按钮、类型按钮与「接着看」都是普通按钮，类型按钮带 `aria-pressed`，`Esc` 回地图。词典另有 3 项大组页内目录锚点，点关联词条跳转后焦点落到目标卡片的 `summary`；分区标题是 `<h3>`，筛空时随卡片一起隐藏。自助工具箱与慢变量同样用 `details / summary`，状态、变量与分类都是普通按钮，`Esc` 回地图。慢变量另有 4 项页内目录锚点；变量 / 状态面板带局部 `aria-live="polite"`，只切分类时不会重复播报说明。
- 静修间的场景按钮带 `aria-pressed`，步骤点只是装饰、不进朗读；练习页每次只显示一步，不用整页 `aria-live` 播报，避免打断用户自己的节奏。
- 弹窗的 `role="dialog"` 用 `aria-labelledby` 指向实际标题元素（没有标题才退回 `aria-label="对话框"`）；焦点进入弹窗、关闭后归还，Tab 焦点陷阱；`#overlay` 本身不再挂 `aria-live`，避免整个弹窗被重复播报。反馈区与记忆牌进度、贝壳数仍用局部 `aria-live="polite"`。
- 进度格只给当前这一站标 `aria-current="step"`；记忆牌按「未翻开 / 已翻开 / 已配对」给出 `aria-label`；词典、自助、慢变量的英文词条都标 `lang="en"`，避免中文语音引擎误读。
- 隐私写入失败提示带 `role="status"`。
- 字号三档、减少动画开关、高对比模式；`3-6 岁` 档自动放大按钮与点击目标。
- 进度格视觉是 9px 细条，但按钮盒撑到 30px（3-6 档 40px），保证触摸目标。
- **急救入口在所有屏都够得到**：顶栏吸顶常驻；弹窗遮罩会盖住顶栏，所以每个弹窗内另有一个「先缓一缓」直达出口。整屏重建统一回到页面顶部，但从急救返回已通关的关卡时保留结果卡位置。
- **结果卡按当前题的深度分级**：3-6 档、以及 6-12 岁档的基础层默认只见一句话、收集与下一步，机制 / 规格 / 生活迁移折进「给大人看」；切到「多想一步」或亲子 / 成年档保持完整六行。首站天气主按钮默认可用，不选也能一次点走。词典「按概念读」的 16 张卡默认收起，不再挤掉首屏。
- 跟随系统 `prefers-color-scheme` 切换深浅色，只换一层 CSS 变量，不新增设置项、不写存档、不联网；高对比模式优先级更高，两套覆盖不叠加。
