# 心情闯关岛

> 一起认出心里的天气。按年龄分级的情绪启蒙小游戏：**纯前端 · 零依赖 · 不联网 · 不打分 · 不采集心情文本**。
>
> 当前版本 **0.8.2**（0.x 预发布台阶，历史批次已自 v0.1.0 重排，见 [CHANGELOG.md](CHANGELOG.md)）｜后续安排见 [ROADMAP.md](ROADMAP.md)

这不是心理测评，也不能代替专业帮助。它做的事只有一件：把模糊的感觉看得更清楚一点，再带走一个用得上的小工具。

---

## 1. 快速开始

| 方式 | 操作 | 适用场景 |
| --- | --- | --- |
| 直接打开 | 双击 `index.html` | 日常使用。`file://` 下完整可玩，已实测 |
| 本地服务 | `npm run serve` → `http://localhost:5173` | 手机同网段预览；以后加 service worker 需要 http |

`npm run serve -- 8080`（或 `node scripts/serve.mjs 8080`）可指定端口。**应用本身不需要 Node、不需要构建、不需要安装依赖**；Node.js 18+ 只用于内容自检、本地静态服务和浏览器回归。

首次进入先选年龄段，之后从设置里可随时更换；换档保留进度、词卡和本领，不会覆盖用户手动调过的字号与朗读偏好。

## 2. 内容规模（当前实测）

| 项目 | 数量 |
| --- | --- |
| 年龄档 | 5 档：`a3` 3-6 岁 / `a6` 6-9 岁 / `a9` 9-12 岁 / `all` 亲子全年龄 / `adult` 成年 |
| 关卡轨 | 2 条：儿童与亲子共用 `kid`；成年独立 `adult` |
| 岛屿 | 每轨 4 座（儿童：察觉湾 / 调节林 / 联结港 / 安放角；成年：觉察滩 / 调节林 / 联结港 / 安放角） |
| 站点 | 每轨 **17 站 = 16 关 + 终章** |
| 玩法 | 13 种互动题型 + 终章，共 14 个 `type` |
| 题库变体 | 儿童 **91 组**，成年 **32 组**，合计 123 组；每档每关至少 2 组 |
| 内容库 | 词卡释义 27 条 · 金句 6 · 聊卡 10 · 微行动 8 · 装饰 6 · 漂流瓶 16 · 静修练习 10 · **心理学词典 155 条（3 大组 / 11 主题 / 4 类概念，每条带关联词条）** · **自助工具 32 张 + 认知扭曲 10 条** · **慢变量 6 个 + 练习 12 张（按 6 变量归属，数量不等）+ 尺度 3 个 + 陷阱 10 个** |

两条轨的关卡 `id` 前缀不同（儿童 `1-1…4-4 / finale`，成年 `A1-1…A4-4 / A-finale`），进度天然隔离，`clearedInTrack()` 各算各的；成年档不显示也不发放贝壳。**词卡也按轨记录**（`state.cards = { kid, adult }`）：两轨同名的 5 张卡（觉察 / 身体信号 / 强度 / 火气分级 / 边界）在各自图鉴里独立解锁，不会因为玩过儿童档就点亮成年图鉴。

## 3. 项目结构

```
.
├── index.html                    # 容器 + 内容文件加载顺序（顺序敏感）
├── style.css                     # 浅色主题、字号/动效/高对比、3-6 档大按钮
├── script.js                     # 全部逻辑：状态 / 渲染器 / 动作分发 / 事件 / 存档迁移
├── content/                      # 纯数据，零逻辑，挂到 window.MI
│   ├── bands.js                  # 5 个年龄段
│   ├── levels-kid.js             # 儿童/亲子主线（岛 1-3 + 终章）
│   ├── levels-kid-island4.js     # 岛 4 四站，插在终章之前
│   ├── levels-adult.js           # 成年独立关卡表
│   ├── bank-kid-1-3.js           # 儿童题库（岛 1-3）
│   ├── bank-kid-island4.js       # 儿童题库（岛 4）
│   ├── bank-adult-1-3.js         # 成年题库（岛 1-3）
│   ├── bank-adult-island4.js     # 成年题库（岛 4）
│   ├── library.js                # 词卡释义/金句/聊卡/微行动/装饰/漂流瓶/静修间
│   ├── dictionary.js             # 心理学词典 155 条 + dictionaryMeta（纯数据，3 组 / 11 主题 / 4 类型）
│   ├── selfhelp.js               # 自助工具箱：5 状态 / 32 工具卡 / 10 条认知扭曲（纯数据）
│   └── slowvars.js               # 慢变量：6 变量 / 12 练习（v 指向变量 id）/ 3 尺度 / 10 陷阱（纯数据）
├── scripts/
│   ├── lint-content.mjs          # 内容自检（用 vm 按加载顺序执行 content/*.js）
│   ├── regression.mjs            # 无头 Chrome 浏览器回归（注入测试页，不改源文件）
│   └── serve.mjs                 # 零依赖静态服务，导出 createStaticServer() 供回归复用
├── tests/
│   └── browser-tests.js          # 69 项浏览器用例，由 regression.mjs 注入
├── package.json                  # check / lint / serve / test:e2e / verify
├── .gitignore
├── README.md  CHANGELOG.md  ROADMAP.md
```

**为什么不用 ES module**：`content/*.js` 用经典 `<script>` 顺序加载，是为了让双击 `index.html` 的 `file://` 场景也能跑（ES module 在 `file://` 下会被 CORS 拦住）。`index.html` 里的顺序是契约：

`bands → levels-kid → levels-kid-island4 → levels-adult → bank-kid-1-3 → bank-kid-island4 → bank-adult-1-3 → bank-adult-island4 → library → dictionary → selfhelp → slowvars → script.js`

顺序错了或文件缺失，`script.js` 启动时会显示「内容没加载出来」的可读提示，不会白屏。

## 4. 怎么加内容

### 4.1 加一组变体（最常见）

在对应的 `bank-*.js` 里往**已有的**该关数组末尾追加一条，并带上档位标记 `b`：

```js
/* 注意是 push，不要用 Object.assign 覆盖整个键——那会把已有变体清掉 */
(MI.bankKid['4-2'] ||= []).push({
  b: ['a6', 'a9', 'all'],
  scenario: '……', question: '现在大概到哪一档？',
  rungs: [{ label: '一档', body: '……', move: '……' }]
});
```

`b` 省略表示该组对所有档可用；`pickVariant()` 按当前档过滤，且避免连续两次抽到同一组。新关卡第一次建键时才用 `Object.assign(MI.bankKid, { 'x-y': [...] })`。

### 4.2 加一站

1. 在 `levels-*.js`（或新建的 `levels-*-islandN.js`）里加一条关卡对象，**必须插在终章之前**；照 `levels-kid-island4.js` 的 IIFE + `splice` 写法最省事；
2. 在对应题库文件里加同名键，每档至少 2 组变体；
3. 如果这一站带新词卡，在 `library.js` 的 `CODEX` 里补释义和例子。

关卡对象字段：`id / island / num / name / type / kind / card / skill / goal / tip / hint / tryIt / adult`。终章固定 `island: 0` 且 `type: 'finale'`，**必须排在数组最后**；位置错了 lint 会直接报错。

### 4.3 加一座岛

照 `levels-kid-island4.js` + `bank-kid-island4.js` 的写法：关卡文件用 IIFE 把新站 `splice` 到终章之前，题库文件用 `Object.assign` 合并；然后在 `MI.kid.islands`（或 `MI.adult.islands`）加一条岛屿描述，最后在 `index.html` 里按依赖顺序插入两行 `<script>`。**别忘了把新文件名加进 `scripts/lint-content.mjs` 顶部的 `FILES` 数组**，否则自检不会读到它。

### 4.4 加一种题型

需要动四处：`script.js` 的 `RENDERERS`（渲染）、`makePlay`（初始化 play 状态）、`ACTIONS`（交互处理）、`style.css`；以及 `lint-content.mjs` 的 `TYPES` / `NEED`。参考 `ladder` 这个题型，它是最小实现。

### 4.5 加 / 改词典词条

词典是独立数据文件 `content/dictionary.js`：`MI.dictionary` 是词条数组，`MI.dictionaryMeta` 定义分组与概念类型。每条字段：

```js
{
  t: '依恋', e: 'Attachment', c: '发展与人格', k: 'core',
  s: '一句话释义（卡片正面）',
  d: '展开解释，写清边界与争议',
  m: '常见误解（可选，暖色块单独显示）',
  r: ['气质', '亲密关系中的依恋']       // 可选：关联词条，渲染成「接着看」
}
```

- **数量不设上限**。0.8.2 起取消「固定 100 条」，`npm run lint` 只保留一条「少于 100 条即报错」的防误删下限。加词条不必删旧词条，也不必同步改测试里的数字（浏览器用例一律读 `DICTIONARY.length`）。
- `c`（主题）与 `k`（概念类型）**只认 `MI.dictionaryMeta`**：`groups[]` 的 `cats` 展开即合法主题，顺序就是词典页的分区顺序；`kinds[]` 的 `id` 是合法类型。当前 **3 个大组 / 11 个主题 / 4 种类型**（`core` 入门核心 / `frontier` 当代议题 / `method` 方法与证据 / `myth` 容易误读）。**新增主题或类型只改数据文件**，不用动 `lint-content.mjs` 与 `script.js`。
- 必填 `t / e / c / k / s / d`，`t` 不重复；`r` 若给出，必须是真实存在的词条名、不能指向自己、不能重复。改完跑 `npm run lint`，它会校验字段、主题、类型、关联引用、名词去重、每个主题 / 类型都有词条与文案长度。
- **交互契约**：`dictCat`（主题）/ `dictKind`（类型）/ `dictQuery`（搜索）只在内存里，每次从入口打开词典都会清空；三个筛选可叠加，计数与分区标题的条数一起更新，分区被筛空时标题跟着收起。点卡片底部的「接着看」会先清掉全部筛选、再滚动并展开目标卡，避免「点了没反应」。分类按钮数量、类型按钮数量、页内目录锚点、卡片类型角标全部由数据派生。
- 写内容时优先用可重复的研究结论，对效应量与争议保守表述；不写诊断、疗效或个体化建议。三条知识库仍共用 `renderLibraryView`，词典只通过可选钩子（`groupTitle / catNameHtml / queryKind / countText / syncSelection / active`）扩展，自助工具箱与慢变量不受影响。

### 4.6 加 / 改自助工具卡

自助工具箱是独立数据文件 `content/selfhelp.js`，对象挂在 `MI.selfhelp` 上，分三块：

- `states`：当下状态卡，固定 **5 种**，字段 `id / name / sub / lead / moves[{t,d}] / avoid`，每种至少 3 个可做动作；
- `tools`：工具卡，固定 **32 张**，字段 `t / e / c / when / how[] / note`，`c` 必须是既有分类之一（心力恢复 / 认知自助 / 行为与身体 / 关系与支持 / 自助边界），`how` 至少 2 步；
- `distortions`：认知扭曲速查，固定 **10 条**，字段 `t / d / eg`。

顶部 `safety` 是边界说明，不可删。改完跑 `npm run lint`，它会检查数量、分类、字段、名称去重与结构。写内容时只做科普与一般性练习，不写诊断、疗效、个体化方案；对证据强度保守表述，危机情况明确指向当地急救与专业支持。

### 4.7 加 / 改慢变量

慢变量是独立数据文件 `content/slowvars.js`，对象挂在 `MI.slowvars` 上：

- `vars`：慢变量，固定 **6 个**，字段 `id / name / sub / lead / why / misuse / move{t,d} / check`；`id` 用小写字母 / 数字 / 连字符，是练习卡唯一的关联键；
- `practices`：练习卡，固定 **12 张**，字段 `t / e / v / when / how[] / note`。**`v` 必须是某个 `vars[].id`**：选中该变量时，练习卡区按 `v` 自动筛到相关卡片；分类按钮的显示名由 `vars[].name` 派生，不另存一份分类表。`how` 至少 2 步；卡片按 `vars` 顺序排列，分类按钮因此与变量同序。每个变量至少 1 张卡，数量不必相等；
- `horizons`：时间尺度，固定 **3 个**（三个月 / 一年 / 十年），字段 `t / d / asks[] / cards[]`，`asks` 至少 2 个问题，`cards` 引用 `practices[].t`，把「往远看」落回一张能动手的卡；
- `traps`：快变量陷阱，固定 **10 条**，字段 `t / d / eg`；名称不得与自助工具箱的 10 条认知扭曲重复。

顶部 `safety` 是边界说明，不可删。改完跑 `npm run lint`，它会检查数量、`v` 是否指向真实变量、每个变量是否都有卡、`cards` 交叉引用、变量与卡片重名、旧字段 `c` 残留、陷阱 / 尺度去重与字段完整性。写内容时不要把慢变量做成新的 KPI 或打卡系统；保持“阅读与选择”，不写评判、诊断或个体化建议，涉及身体与情绪持续不适时指向医生或专业支持。

**交互契约**：`svVar`（选中的变量）和 `svCat`（当前筛选）只在本次打开期间存在，每次从入口打开慢变量页都会清空两者。选变量会把 `svCat` 一起设为该变量 id；手动点分类只改 `svCat`、保留变量面板；非法 id 直接忽略。卡片与筛选都不落盘。

### 4.8 改完必跑

```bash
npm run verify      # = 语法检查 + 内容自检 + 69 项浏览器回归 + 18 项源码检查
```

## 5. 存档与迁移

| 项 | 值 |
| --- | --- |
| 当前键 | `mood-island-v4` |
| 旧键 | `mood-island-v3`（0.7.0 及更早）、`mood-island-v2`（读到后自动迁移；正常升级时**旧键保留**以便回退，「清空本机进度」会连旧键一起删除） |
| schema 版本 | `SCHEMA_VERSION = 4` |
| 字段 | `version, band, cleared, awarded, cards{kid[],adult[]}, skills, shells, decor, settings{scale, motion, speak, speakTouched, autoSpeak, contrast}` |
| id 改名 | `ID_REMAP = { '3-5': 'finale' }`，旧终章进度不会丢 |

`load()` → `readRaw()`（v4 优先，v4 损坏或不存在时回退 v3 / v2）→ `migrate()`。**以后加任何字段，都在 `migrate()` 里补一段白名单式默认值**，不要直接改 `DEFAULT_STATE` 就完事，否则老用户进度可能被静默重置。`migrate()` 还会逐项清掉无效数据：未知关卡 id、重复的 `cleared / awarded`、内容里已不存在的词卡与本领、越界或重复的 `decor` 下标、负数或小数的 `shells`、不在允许档位里的 `settings.scale`；其余字段不受影响，所以旧档和现有 v4 档都不会被整体重置。

**v3 → v4 只改词卡语义**：旧档的 `cards` 是不分轨的数组，`migrateCards()` 按以下顺序推断归属——① 只在一轨出现的卡，直接归该轨；② 两轨同名的卡，对应关卡有通关 / 领贝壳记录就归该轨，两轨都有记录则两边都算真拿到；③ 对不上记录时，只玩过一轨就归那一轨；④ 两轨都玩过但仍无法判定，归**儿童档**（宁可少给成年档，也不把儿童卡虚增成成年卡）。`cleared / awarded` 不受影响。

**`skills` 暂不按轨拆分**：两轨现在没有同名本领，所以共用一份数组不会串档；回归会断言两轨本领名不重复。以后若要复用同一个本领名，必须先把 `skills` 拆成按轨结构并补迁移，否则会在另一轨提前点亮。词卡已经按轨拆分（`cards: { kid, adult }`），不受这个约束影响。

**回退**：正常升级时旧键从不被新代码覆盖，旧版本代码仍读 v3；升级后产生的新进度只写 v4，回退到旧代码会看不到升级后的新进度，但不会破坏旧档，也不会把词卡串档。用户点「清空本机进度」是明确的删除动作，会移除 v4 / v3 / v2，之后不能再靠旧键找回。

**不会保存**：开场选的天气、任何心情文本（应用不提供心情输入框；词典搜索框只做本地过滤）、心理学词典的主题 / 类型 / 搜索词（每次重新打开都会清空）、自助工具箱选中的状态与分类、慢变量选中的变量与分类（每次重新打开都会清空）、练习次数、静修间做过几次。隐私 / 无痕模式下若 `localStorage` 不可写，页面会常驻一条说明、设置页同步提示，不会谎报「已保存」。

**已决取舍**：v0.6.0 之前成年档与儿童档共用 `1-1…3-4` 这些 id；双轨拆分后这些 id 归儿童轨，成年轨会显示为「未走过」。两套题本来就不同，**目前处于开放阶段，明确不做进度映射，也不再排期**。

## 6. 命令

| 命令 | 作用 |
| --- | --- |
| `npm run check` | `node --check script.js`，只查逻辑文件语法 |
| `npm run lint` | 内容自检，不引依赖、不启浏览器 |
| `npm run serve [端口]` | 本地静态服务，默认 5173；传参写 `npm run serve -- 8080` |
| `npm run test:e2e` | 无头 Chrome 回归（69 项用例 + 18 项源码检查），约 1.5 秒 |
| `npm run verify` | check + lint + test:e2e，**每次提交前至少跑这个** |

`test:e2e` 需要本机有 Chrome / Chromium；找不到时设置 `CHROME_PATH=/path/to/chrome`。测试页是在内存里注入用例生成的临时 HTML，**不会改动任何源文件**，也不写项目目录。

## 7. 设计红线（改动前先读）

1. **不打分、不排名、不比速度**：没有分数、正确率、倒计时、失败惩罚、红叉、连签、排行榜。答错给中性提示，连续两次未命中自动给 `hint`。
2. **不采集心情文本**：没有心情自由输入框，天气选择不落盘，不记练习次数。漂流瓶选哪一项都给同一句回应，没有对错。心理学词典的搜索框只在当前页面内过滤词条，不保存、不上传，也不接收心情文本；主题与类型筛选同样只在内存里，每次重新打开都会清空。自助工具箱与慢变量只提供阅读与选择，不收集自由文本，选中的状态、变量和分类只留在内存里，慢变量每次重新打开都会清空。
3. **不联网**：没有 fetch/XHR、没有第三方脚本、字体、图标或 CDN；朗读调用设备自带语音能力。
4. **不宣称疗效**：不是心理测评、不是诊断、不能代替专业帮助；页脚与静修间双重免责，呼吸/正念练习可睁眼、随时停止。「睡不着」组不承诺助眠，只说「不把睡着当任务」。
5. **不制造回来的压力**：不打卡、不连续登录奖励、进度不会掉；静修间只是排列成四组，不是筛选器，也不要求先描述感受。
6. **正确答案不能恒在第一项**：`clue / reframe / defuse / compose` 渲染前洗牌，判对错读 `data-orig` 的原始下标。

新增内容若碰到这些边界，先改设计再写代码。`lint-content.mjs` 会扫红线词，但最终仍需要人工判断语境。

## 8. 键盘与无障碍

- 选项左侧徽标是 **1 / 2 / 3…**，直接对应数字键。`1`–`9` 覆盖所有使用 `.opt` 的选择题（线索单选、换视角 `reframe`、终章金句、静修「第一反应」）以及漂流瓶弹窗里的选项；梯子的档位号也能按。天气、配对、滑杆、排序、拼句、记忆牌没有数字键，仍用 Tab / 点击。
- `Esc` 关弹窗 / 回地图，`←` `→` 在已解锁的站之间切换（仅关卡视图）。
- 心理学词典的卡片用原生 `details / summary`：Tab 可聚焦，Enter / 空格展开；搜索框可输入，分类按钮、类型按钮与「接着看」都是普通按钮，类型按钮带 `aria-pressed`，`Esc` 回地图。词典另有 3 项大组页内目录锚点，点关联词条跳转后焦点落到目标卡片的 `summary`；分区标题是 `<h3>`，筛空时随卡片一起隐藏。自助工具箱与慢变量同样用 `details / summary`，状态、变量与分类都是普通按钮，`Esc` 回地图。慢变量另有 4 项页内目录锚点；变量 / 状态面板带局部 `aria-live="polite"`，只切分类时不会重复播报说明。
- 弹窗的 `role="dialog"` 用 `aria-labelledby` 指向实际标题元素（没有标题才退回 `aria-label="对话框"`）；焦点进入弹窗、关闭后归还，Tab 焦点陷阱；`#overlay` 本身不再挂 `aria-live`，避免整个弹窗被重复播报。反馈区与记忆牌进度、贝壳数仍用局部 `aria-live="polite"`。
- 进度格只给当前这一站标 `aria-current="step"`；记忆牌按「未翻开 / 已翻开 / 已配对」给出 `aria-label`；词典、自助、慢变量的英文词条都标 `lang="en"`，避免中文语音引擎误读。
- 隐私写入失败提示带 `role="status"`。
- 字号三档、减少动画开关、高对比模式；`3-6 岁` 档自动放大按钮与点击目标。
- 进度格视觉是 9px 细条，但按钮盒撑到 30px（3-6 档 40px），保证触摸目标。
