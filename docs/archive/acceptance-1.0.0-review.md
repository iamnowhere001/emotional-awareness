#### 逐条说明与条件本身的修订建议

1. **条件 1：满足。** 实跑输出为 `回归 115 项 + 源码检查 51 项：166 PASS / 0 FAIL`；lint 输出「内容自检通过」，0 错误，5 条提示（两条终章未挂概念，以及「排名 / 治疗 / 诊断」语境提示）。条件本身不过时；建议保留，但补一句「提示条目不阻断，但发布前需人工确认语境」。
2. **条件 2：2/3 已实测，PWA 实际安装未取得。** `file://` 与 http 已按同一主线走通；PWA 侧证明了可安装（manifest 可解析、`installabilityErrors` 为空）、SW 控制下能完成主线、停服后能重载，但没有真正从浏览器 UI 安装到主屏。建议把条件改成「三种入口各有一份带日期、浏览器 / 设备、入口方式、走通的关卡 id 的验收记录；PWA 安装一项若无法自动化，需由人工补一次并注明设备」。
3. **条件 3：已满足。** 新增端到端用例用同一份导出载荷走完「导出 → 清空 → 导入 → 全字段一致」，迁移仍由旧用例与源码断言覆盖。条件原文不必改。
4. **条件 4：不可由仓库判定，且已明确由用户本人执行。** 号码与服务范围是外部事实，儿童措辞是人工判断。建议改为「存在带日期与复核人的复核记录」，并把「号码当期有效」标为发布当日的外部检查项。
5. **条件 5：文档一致性已收口，只剩 0.12.0 例外。** 本轮修掉 §4.2 / §6 / §5.2 / §5.3 / README 的陈旧标注，并在 §4.3 把 0.12.0 的拆分提交 + 文档提交写成唯一例外。原文「一一对应」仍与历史不符；建议改成「自 0.13.0 起一一对应，0.12.0 为已记录例外」。

PWA / 离线：

- **安装性**：CDP `Page.getAppManifest` 返回 `http://127.0.0.1:5190/manifest.webmanifest`、`errors: []`；`Page.getInstallabilityErrors` 返回 `installabilityErrors: []`。这只证明浏览器认为可安装，**不等于已安装**。
