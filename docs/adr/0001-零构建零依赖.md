# ADR-0001 零构建、零依赖

- 状态：Accepted（2026-11-26）
- 日期：2026-11-26

## 上下文

使用者是会双击文件的家长和孩子，不是开发者。产品要求「下载即玩、断网可用、不上传任何数据」；仓库里没有 `node_modules`，也没有 `package-lock.json`。

## 决定

应用本身不含构建步骤、不引 npm 依赖、不含 TypeScript、不引框架与 CDN。Node.js 只用于内容自检、本地静态服务和浏览器回归，**不是运行前提**。

## 后果

放弃的：模块化编译、tree-shaking、类型检查、生态复用、按需加载。
换到的：`file://` 双击完整可玩；没有构建产物可腐坏；任何改动刷新即见；依赖供应链攻击面为零。

## 复核条件

只有产品决定改为「必须安装 PWA 或走应用商店」时才重开。仅凭「工程规范要求有构建流程」不足以重开——本项目没有可被构建优化的体积，也没有服务端。
