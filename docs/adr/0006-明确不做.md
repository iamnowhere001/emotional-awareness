# ADR-0006 明确不做的功能

- 状态：Accepted（2026-11-26）
- 日期：2026-11-26

## 上下文

这是一个情绪启蒙小游戏，不是 SaaS。每加一个「留存功能」，就要多一份数据、多一个回访压力，并且往往与六条红线正面冲突。

## 决定

**不做**：云同步 / 账号 / 打卡与连续天数 / 提醒推送 / 多语言 / 金句 PNG 分享。
前四项与红线冲突（不联网、不采集、不打卡、无服务端），后两项不解决任何现有断点。

## 后果

放弃的：跨设备进度、病毒式传播、多语言市场。
换到的：数据完全不出本机；没有服务器成本与合规义务；产品不需要「运营」。

## 复核条件

任一项要重开，必须先在 `ROADMAP.md` §2 里论证它解决了哪个**具体断点**，并说明红线如何不被破坏。仅凭「竞品都有」不足以重开。
