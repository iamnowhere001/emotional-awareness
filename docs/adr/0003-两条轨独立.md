# ADR-0003 儿童轨与成年轨完全独立

- 状态：Accepted（2026-11-26）
- 日期：2026-11-26

## 上下文

同一个应用要同时服务 3-6 岁、6-12 岁、亲子与成年四档。儿童档需要降级术语、回避丧失意象；成年档需要概念密度与工作场景。两边的文案、题型配比、进度都不能互串。

## 决定

`kid` 轨（`a3 / a6 / all`）与 `adult` 轨的关卡表、题库、叙事、进度、词卡各自独立，`clearedInTrack()` / `cardsInTrack()` 各算各的。**不为省事复用儿童壳。**

## 后果

放弃的：内容复用率（同一话题两轨各写一遍，若干概念还有两轨双名）；组件层可复用性（渲染器共用，数据完全不共用）。
换到的：改儿童文案不会伤到成年档，反之亦然；两轨词卡独立解锁，玩过儿童档不会点亮成年图鉴。
已知例外：`state.skills` 与 `state.shells` **不**按轨隔离，靠「两轨没有同名本领」的约定 + 回归断言撑着。

## 复核条件

只有出现第三类用户（例如「青少年档」）且其内容复用率低于某个可测阈值时才重开。仅凭「两套内容维护成本高」不足以重开——那正是这条 ADR 接受的代价。
