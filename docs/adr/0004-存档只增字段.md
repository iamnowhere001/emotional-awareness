# ADR-0004 存档只增字段

- 状态：Accepted（2026-11-26）
- 日期：2026-11-26

## 上下文

使用者是家庭，一台设备可能被两个年龄段的人先后使用；进度丢失是无法解释也无法补偿的故障。历史上已发生过一次 TDZ 事故（`let` 声明晚于 `let state = load()`，症状是「刷新后进度全丢」）。

## 决定

存档只增字段、不改既有字段语义；结构变更必须同批 bump `SCHEMA_VERSION` + 补 `migrate()` 分支 + 用旧档 JSON 实测；旧键（v2/v3/v4）迁移后**保留**以便回退，不删除。

## 后果

放弃的：键名自由（`cards` 存的是显示名，两轨双名就占两个键）、结构整洁（旧键长期留着）、「一次重构把 schema 理顺」的诱惑。
换到的：任何一次升级都能回退；坏档时另有 `mood-island-v5-corrupt` 留底（原始字符串 + 原键名 + 时间戳）。

## 复核条件

只有产品决定「放弃老用户进度、要求重新开始」时才重开。仅凭「旧键清理掉更干净」不足以重开——那会让回退路径消失。
